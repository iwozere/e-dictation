# e-dictation

A structured dictation platform for language teachers and their students. Teachers create dictations from text; students practice with AI-generated speech that supports sentence-level navigation, adjustable playback speed, and configurable pauses between sentences.

---

## What it does

### For teachers
- Sign up and create a teacher account
- Paste dictation text (up to 500 words) and set metadata: title, language, difficulty, default pause duration
- The platform automatically splits the text into sentences (using Claude AI) and generates high-quality neural speech for each sentence (using Google Cloud TTS Neural2)
- Organise dictations into classes/groups
- Share any dictation with students via a **6-character code** or a direct link — no student account required

### For students
- Open a dictation via share link (`/d/XXXXXX`) or enter a code — no account, no app install
- Listen to each sentence as a discrete audio clip, with a configurable pause between sentences
- Control playback: play/pause, repeat current sentence, skip forward/back, restart
- Adjust speed: 0.5×, 0.75×, 1×, 1.25×
- Adjust pause between sentences: 2 s, 5 s, 10 s
- Four text visibility modes:
  - **Listen only** — text fully hidden (genuine exam mode)
  - **Reveal after** — each sentence appears only after its audio plays
  - **Partial hint** — first and last word visible
  - **Full transcript** — complete text always shown

## Architecture

### Player model: sentence playlist, not audio scrubber

The player works on **sentence index**, not continuous waveform position. Each sentence is a discrete MP3 file stored in Supabase Storage. The `PlaybackNotifier` steps through the sentence array with a `Future.delayed()` pause between items.

This enables:
- Repeat one sentence without re-encoding anything
- Configurable pause gap (set by teacher, overridable by student)
- Jump to any sentence by index
- Reveal text sentence-by-sentence in sync with audio

### TTS pre-generation (cost and performance)

Audio is generated **once at save time**, never at playback:
1. Teacher saves dictation text
2. `on_dictation_save` Supabase Edge Function fires
3. Claude splits the text into sentences (handles German abbreviations, quoted speech, ellipses)
4. Google TTS Neural2 generates an MP3 per sentence
5. MP3s uploaded to `supabase-storage/dictations/{id}/sentence_{n}.mp3`
6. `dictation_sentences` table rows written with `audio_url` and `duration_ms`

Cost per dictation: ~$0.016 (200 words, generated once, cached forever).

### Student access model

Students access dictations anonymously via share code. Supabase anonymous sign-in creates a scoped session so Row-Level Security policies can grant read access to the shared dictation without exposing any other data. Students are never asked to create an account.

## Database schema

Five tables, all with Row-Level Security enabled:

| Table | Purpose |
|---|---|
| `profiles` | Extends Supabase Auth — stores `role` (teacher/student) and `display_name` |
| `classes` | Teacher-defined groups for organising dictations |
| `dictations` | One row per dictation — title, language, text, share code, default pause |
| `dictation_sentences` | One row per sentence — position, text, `audio_url`, `duration_ms` |
| `attempts` | Student submissions with scored results (Phase 3) |

Share codes are 6-character uppercase alphanumeric strings generated by a database trigger on every dictation insert.

```bash
# Install dependencies
flutter pub get

# Run on web
flutter run -d chrome \
  --dart-define=SUPABASE_URL=https://your-project.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=your-publishable-key
```

Or use the local convenience script (gitignored, contains your keys):
```bash

```

## Roadmap

### Phase 1 — MVP ✅ (current)
Teacher creates dictation → student plays it with sentence-level controls and dictation mode

### Phase 2 — Enhanced UX
- Teacher voice input via microphone → Whisper STT → editable text → TTS
- Sentence highlight during playback
- Sentence repeat button
- Student accounts (optional, saves progress)

### Phase 3 — AI & Analytics
- Student submits typed text after dictation
- AI mistake analysis: spelling, grammar, umlaut errors, noun capitalisation (German)
- Teacher dashboard: per-student and per-class results
- Adaptive practice based on recurring errors

### Phase 4 — Growth
- Premium voices (ElevenLabs)
- French, Spanish, Italian
- PDF export of results
- LMS integrations (Google Classroom, Moodle)
- Public dictation library
